This panel is the structural screen now. Code no longer refuses a token for a thin pool, weak smart money, top-10 concentration or a dev still holding — those are scored, shown in Soundings, and left to the analyst to reject. Set them here if you want them enforced.

Switch to live trading

Live mode sends real, irreversible swaps from your wallet using the GMGN API. Positions can go to zero. Only trade funds you can afford to lose entirely.

The CLI also requires GMGN_ALLOW_AUTOMATED_TRADES=1 in the shell you started this server from. That variable is your consent to headless execution — set it yourself, deliberately.
